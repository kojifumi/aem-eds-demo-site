よくある質問

導入前に知っておきたいことをまとめました。

Nexara AI をどのくらいの期間で導入できますか？
多くのチームが 2 週間以内に本番運用を開始しています。実装スペシャリストがデータ接続、モデル設定、トレーニングまで伴走します。インフラの変更は不要です。
データのセキュリティとプライバシーは守られますか？
はい。Nexara AI は SOC 2 Type II 認証を取得し、GDPR に準拠しています。プライベートクラウドやオンプレミスでの展開にも対応。お客様のデータが他社モデルの学習に使われることはありません。
データサイエンスチームは必要ですか？
いいえ。ビジネスチーム向けに設計されており、ノーコード UI で誰でもモデルの構築・学習・デプロイが可能です。必要に応じてフルマネージドサービスもご利用いただけます。
どのような連携が利用できますか？
Salesforce、HubSpot、Slack、Microsoft 365、Google Workspace、Snowflake、Databricks など 200 以上のプラットフォームとネイティブ連携。REST API とプリビルトコネクタも提供しています。
料金プランを教えてください。
Starter（最大 3 ユーザー・月額 0 円）、Growth（月額 45,000 円相当）、Enterprise（個別見積）をご用意。全プランで 14 日間の無料トライアルが可能で、クレジットカード登録は不要です。
