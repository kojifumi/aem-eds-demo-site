FAQ

よくある質問

カスタム連携は可能ですか？

REST API と Webhook で任意のシステムと接続できます。Enterprise プランでは専用コネクタ開発も対応します。

データはどこに保存されますか？

リージョン選択可能な SOC 2 Type II 認証データセンターに暗号化保存されます。
